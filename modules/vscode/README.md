# BlueForest theme for VS Code

The BlueForest colour theme for VS Code and VS Code-compatible editors. The
extension identifier is `alonsodomin.blueforest-theme`, and the theme is named
**BlueForest** inside the editor.

Install it from [Open VSX](https://open-vsx.org/extension/alonsodomin/blueforest-theme),
which is the recommended source for VS Code-compatible editors. Installation
from the VS Marketplace, from a release VSIX, and with Nix is documented at
<https://alonsodomin.github.io/blueforest-theme/themes/vscode/>.

For the repository layout and contribution workflow, see the
[Hacking section](https://alonsodomin.github.io/blueforest-theme/hacking/).
