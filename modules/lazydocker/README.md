# BlueForest theme for lazydocker

The BlueForest theme for [lazydocker](https://github.com/jesseduffield/lazydocker),
the simple terminal UI for Docker and Docker Compose. lazydocker has no theme
file of its own: the theme is the `gui.theme` mapping of its configuration
file, and the file of this application carries it under that key.

Download the theme from the
[GitHub releases](https://github.com/alonsodomin/blueforest-theme/releases) or
install it with Nix. Both ways are documented at
<https://alonsodomin.github.io/blueforest-theme/themes/lazydocker/>.

For the repository layout and contribution workflow, see the
[Hacking section](https://alonsodomin.github.io/blueforest-theme/hacking/).
