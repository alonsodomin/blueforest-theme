# BlueForest theme for btop

The BlueForest theme for [btop](https://github.com/aristocratos/btop), the
resource monitor. The theme is named `blueforest`, the name of the file
`blueforest.theme`, and btop reads it as a theme of its own directory.

Download the theme from the
[GitHub releases](https://github.com/alonsodomin/blueforest-theme/releases) or
install it with Nix. Both ways are documented at
<https://alonsodomin.github.io/blueforest-theme/themes/btop/>.

For the repository layout and contribution workflow, see the
[Hacking section](https://alonsodomin.github.io/blueforest-theme/hacking/).
