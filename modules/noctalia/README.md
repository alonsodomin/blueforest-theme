# BlueForest theme for Noctalia

The BlueForest theme for [Noctalia](https://noctalia.dev), the Wayland shell
and bar. The theme is a palette named `blueforest`, the name of the file
`blueforest.json`, and Noctalia reads it as a palette of its own configuration
directory.

Download the theme from the
[GitHub releases](https://github.com/alonsodomin/blueforest-theme/releases) or
install it with Nix. Both ways are documented at
<https://alonsodomin.github.io/blueforest-theme/themes/noctalia/>.

For the repository layout and contribution workflow, see the
[Hacking section](https://alonsodomin.github.io/blueforest-theme/hacking/).
