# BlueForest theme for MkDocs

The BlueForest theme for [MkDocs](https://www.mkdocs.org/), with
[Material for MkDocs](https://squidfunk.github.io/mkdocs-material/). The theme
is a stylesheet named `blueforest.css`, and it recolours the code blocks of
the dark scheme of Material.

Download the theme from the
[GitHub releases](https://github.com/alonsodomin/blueforest-theme/releases) or
install it with Nix. Both ways are documented at
<https://alonsodomin.github.io/blueforest-theme/themes/mkdocs/>.

For the repository layout and contribution workflow, see the
[Hacking section](https://alonsodomin.github.io/blueforest-theme/hacking/).
