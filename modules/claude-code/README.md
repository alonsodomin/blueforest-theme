# BlueForest theme for Claude Code

The BlueForest theme for [Claude Code](https://github.com/anthropics/claude-code),
the terminal agent of Anthropic. The theme is named `blueforest`, the name of
the file `blueforest.json`, and Claude Code reads it as a custom theme of its
own directory.

Download the theme from the
[GitHub releases](https://github.com/alonsodomin/blueforest-theme/releases) or
install it with Nix. Both ways are documented at
<https://alonsodomin.github.io/blueforest-theme/themes/claude-code/>.

For the repository layout and contribution workflow, see the
[Hacking section](https://alonsodomin.github.io/blueforest-theme/hacking/).
