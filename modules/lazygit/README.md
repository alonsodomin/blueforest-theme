# BlueForest theme for lazygit

The BlueForest theme for [lazygit](https://github.com/jesseduffield/lazygit),
the terminal UI for git. lazygit has no theme file of its own: the theme is
the `gui.theme` mapping of its configuration file, and the file of this
application carries it under that key.

Download the theme from the
[GitHub releases](https://github.com/alonsodomin/blueforest-theme/releases) or
install it with Nix. Both ways are documented at
<https://alonsodomin.github.io/blueforest-theme/themes/lazygit/>.

For the repository layout and contribution workflow, see the
[Hacking section](https://alonsodomin.github.io/blueforest-theme/hacking/).
