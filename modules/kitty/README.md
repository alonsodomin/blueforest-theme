# BlueForest theme for kitty

The BlueForest theme for [kitty](https://github.com/kovidgoyal/kitty), the
terminal emulator. The theme is named `blueforest`, the name of the file
`blueforest.conf`, and kitty reads it as a theme of its own directory.

Download the theme from the
[GitHub releases](https://github.com/alonsodomin/blueforest-theme/releases) or
install it with Nix. Both ways are documented at
<https://alonsodomin.github.io/blueforest-theme/themes/kitty/>.

For the repository layout and contribution workflow, see the
[Hacking section](https://alonsodomin.github.io/blueforest-theme/hacking/).
