# BlueForest prompt for sbt

The installation of the [sbt-prompt](https://github.com/alonsodomin/sbt-prompt)
plugin with its `BlueforestTheme`. This directory does not define the prompt:
it declares the plugin and selects the theme.

Download the configuration files from the
[GitHub releases](https://github.com/alonsodomin/blueforest-theme/releases) or
install them with Nix. Both ways, including the locations for sbt 1 and sbt 2,
are documented at
<https://alonsodomin.github.io/blueforest-theme/themes/sbt/>.

For the repository layout and contribution workflow, see the
[Hacking section](https://alonsodomin.github.io/blueforest-theme/hacking/).
