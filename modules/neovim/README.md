# BlueForest theme for Neovim

The BlueForest colourscheme for Neovim, with a matching lualine theme. The
colourscheme is named `blueforest`.

Download the theme from the
[GitHub releases](https://github.com/alonsodomin/blueforest-theme/releases) or
install it with Nix, including the nixvim module. Both ways are documented at
<https://alonsodomin.github.io/blueforest-theme/themes/neovim/>.

For the repository layout and contribution workflow, see the
[Hacking section](https://alonsodomin.github.io/blueforest-theme/hacking/).
