# Change Log

All notable changes to the BlueForest theme for Neovim will be documented in
this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.


## Unreleased

- The theme has a light variant now, `blueforest-light`, with the colours of
  the light palette of the repository, and the theme of lualine comes with it
- The theme is added to the plugins of Neovim only when
  `blueforest-theme.neovim.enable` is true
- Initial release: the BlueForest theme for Neovim, packaged as
  `blueforest-neovim-theme`. It carries the colourscheme of Neovim and the
  theme of lualine
- The theme has a module for nixvim as well, which installs it among the
  plugins of the editor and selects the colourscheme
- The variables are painted with the colour of the variables, like the other
  applications of the repository paint them, and not with the colour of the
  identifiers
