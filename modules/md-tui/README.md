# BlueForest theme for md-tui

The BlueForest theme for [md-tui](https://github.com/henriklovhaug/md-tui),
the terminal viewer for Markdown. The theme is named `blueforest`, the name
of the file `blueforest.json`, and md-tui reads it as a palette of its own
directory.

Download the theme from the
[GitHub releases](https://github.com/alonsodomin/blueforest-theme/releases) or
install it with Nix. Both ways are documented at
<https://alonsodomin.github.io/blueforest-theme/themes/md-tui/>.

For the repository layout and contribution workflow, see the
[Hacking section](https://alonsodomin.github.io/blueforest-theme/hacking/).
