# Change Log
All notable changes to the BlueForest theme for md-tui will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.


## 0.4.0 - [05-11-2026]

- The palette has a light variant now, `blueforest-light`, and the switch of the
  variant selects the one that is installed
- Initial release: the theme of md-tui, packaged as `blueforest-md-tui-theme`
- The Home Manager module installs the theme in the directory md-tui reads the
  palettes from, selects it, and it writes nothing when the theme is not
  enabled
